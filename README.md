An entry for the [Two Robots in an Elevator](https://make.fun/bounty/u-motasimfuad-two-robots-in-an-elevator-8c6aeb8f) bounty on [make.fun](https://make.fun): a program that writes one line of awkward small talk that one robot says to another while they ride an elevator together to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

The program is deterministic: it writes the same UTF-8 text (153 characters, no trailing newline) on every run, uses no network, and reads no input.
